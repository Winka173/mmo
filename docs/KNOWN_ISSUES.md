23 October 2026. This list describes gaps rather than hiding them behind installed libraries or routes.

The test install uses a Unicode/spaces path. Clean-machine setup, graceful tray Quit and all interrupted-model cases remain pending; this is not full production acceptance.

5. **Source scheduler is intentionally conservative.** Authorized local folder watcher has content hashes, file stability/cache, pinned intake and per-language dedup; real owned-video fixture and UI persistence pass. Timezone production windows/caps have tests. This does not provide remote authenticated downloading, publishing quotas, semantic novelty or an adaptive opportunity director.
6. **Deduplication has bounded scope.** Manual rerun explicitly bypasses cadence dedup. Modified brief/media may legitimately create a new draft; exact hashing does not prove originality. Failed jobs with unchanged identity require explicit retry rather than being re-generated every slot. Do not purge queue/run history without a retention-aware content ledger.
7. **Quality gates are partial.** Captions use estimated phrase timing unless the optional English aligner passes all guards or the user manually adjusts timing; Vietnamese remains estimated/manual. Matching uses pinned descriptions, including explicitly reviewed keyframe suggestions, not a certified gameplay understanding system. Voice policy v2 catches changed numbers/negations that a low aggregate WER could hide; transcription formatting still needs review. Research/facts/editorial remain unknown. Technical PASS cannot authorize posting.
8. **Editor is partial.** Actual multitrack render, ripple cuts, editable captions after cuts, gains, range zoom, title/audio import with rights and restoring old versions now work in worker/UI fixtures. Narration revisions preserve unrelated voice bytes in untrimmed narration versions; re-narrating an arbitrary cut/timeline clip, full transcript alignment and general semantic edits remain incomplete.
9. **Publishing acceptance is incomplete.** YouTube has channel/revision DPAPI, explicit one-version authorization, OAuth loopback/PKCE UI and persistent automatic delivery AFTER four scoped content reviews. Contracts cover identity/scopes/revocation/hash/reconciliation and product source/disclosure/price/link checks. No real account/login/upload acceptance. This policy does not remove per-video content review or satisfy full exception-only Autopilot approval. Studio Meta/TikTok use manual export.
10. **Telegram delivery semantics.** Durable inbox is persisted before offset, uncertain interrupted actions require confirmation, preview/outbox IDs are deterministic. Scoped review confirmations and per-version publication status have contracts; no live bot acceptance or exactly-once provider delivery guarantee. Exception levels and reports remain partial.
11. **Dependencies and packaging.** Python environments/model weights are separate resources. Current machine setup is not a clean-machine install proof. Legacy tests requiring eSpeak or FFmpeg PATH can fail due to unavailable tools. Never label missing prerequisites PASS.
12. **GPU reliability.** Controlled two-process contention/crash cleanup and engine circuit fault-injection are verified. Real GPU_BUSY during another application's workload has deferred ACS jobs. This does not prove forced physical OOM handling, fairness or all Asset Forge integration cases. No changes may be made to Asset Forge's environment/storage.
13. **Localization/project independence.** Legacy screens/strings may retain old brand/VI-only labels. New shell does not make every error/onboarding screen bilingual.
14. **Model upgrade integrity.** Voice model/codec, runtime/preset/dependency versions and audio cache hashes are checked; the whole project is not a complete immutable checkpoint/consent/dependency manifest. Default normalization preserves internally consistent legacy hashes; full reproducible quality lock remains future work.

See latest [release evidence](RELEASE_QA.md). Remove or narrow an issue only when corresponding commands/artifacts demonstrate the fix; newer work by parallel agents must be reflected with exact evidence scope.
